# Amos

> A guide-dog chatbot for engineers exploring ultrasonic bolt-tension measurement.

Amos is a hybrid **LLM Wiki + RAG** chatbot that answers questions about Predictant's Bolt iQ product and the broader field of ultrasonic bolt-tension measurement. The architecture pairs an agentic Wiki layer (inspired by [Karpathy's LLM Wiki gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)) with a ChromaDB vector index, deployed as two Azure Container Apps — a public demo and a password-gated internal version.
